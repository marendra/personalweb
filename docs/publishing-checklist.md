# Publishing checklist (private)

This document is for authoring discipline. It is **not** a public site page and must not be routed or linked from the website.

Review every piece before changing `status` to `published`.

## Confidentiality

- [ ] No employer-confidential information
- [ ] No customer or partner information that is not already public
- [ ] No proprietary implementation details
- [ ] No security-sensitive architecture (credentials, internal network maps, exploit details, unpublished vulnerability notes)

## Personal boundaries

- [ ] No precise real-time location
- [ ] No private family information
- [ ] No financial information (income, account balances, unpublished commercial figures)
- [ ] No unreleased product plans that are not yours to share

## Emotional hygiene

- [ ] Writing composed while angry or highly emotional has been cooled and re-read
- [ ] Claims about other people are fair, necessary, and non-defamatory
- [ ] You would be comfortable with this text being quoted out of context

## Editorial quality

- [ ] Frontmatter is complete (`title`, `slug`, `description`, `date`, `category`, `tags`, `status`)
- [ ] `status: published` is intentional
- [ ] Placeholder wording has been removed
- [ ] Hero image (if any) has accurate `heroAlt` text
- [ ] Internal links resolve to published pages
- [ ] Code samples do not leak secrets

## Final

- [ ] Re-read the piece once on mobile width
- [ ] Confirm the piece matches the section it lives in (`writing`, `life`, `notes`, `projects`)
